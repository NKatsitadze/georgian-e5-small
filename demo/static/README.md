Demo of [georgian-e5-small](https://huggingface.co/nkatsitadze/georgian-e5-small), a small, fast Georgian
text-embedding model. The lite version runs entirely in the browser with Transformers.js (8-bit ONNX), searching
the opening paragraphs of 30,000 Georgian Wikipedia articles (CC BY-SA 4.0). Optionally compare side by side
with the original multilingual-e5-small. Code: https://github.com/NKatsitadze/georgian-e5-small
